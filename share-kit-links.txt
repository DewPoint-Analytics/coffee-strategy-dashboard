QR CODES (for slides and printed pages)
  qr-site-slides.png    opens the website   (counted as ref: slides)
  qr-report-slides.png  opens the report    (counted as scan: slides)
  qr-site-print.png     opens the website   (counted as ref: print)
  qr-report-print.png   opens the report    (counted as scan: print)

The QR code on the website itself is counted as "scan: website".

WHERE TO SEE THE NUMBERS (GoatCounter dashboard)
  Pages:     /report-scan = report scans, /report-link = report opened another way, / = website visits
  Referrers: which channel each visit came from (linkedin, instagram, substack, github, scan: print ...)
  Also: countries, phone vs computer, browsers, dates.
